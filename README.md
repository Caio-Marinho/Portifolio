# Portfólio

Portfólio pessoal desenvolvido em HTML, CSS e JavaScript para apresentar projetos, habilidades e contatos.

## Visão geral

Este projeto foi criado para funcionar como uma landing page profissional simples, leve e fácil de publicar em qualquer ambiente estático.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Assets locais

## Estrutura do projeto

```text
.
├── assets/
│   ├── img/
│   └── ...
├── css/
│   └── styles.css
├── index.html
├── README.md
└── .hintrc
```

## Como executar

1. Clone o repositório.
2. Abra a pasta do projeto.
3. Inicie o arquivo `index.html` em um navegador.

Você também pode usar um servidor local simples, por exemplo:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```

## Personalização

- Atualize os textos e links em `index.html`.
- Ajuste estilos em `css/`.
- Troque imagens e assets em `assets/`.

## Objetivo

Servir como portfólio pessoal para mostrar perfil, experiência, projetos e formas de contato de maneira clara e profissional.
